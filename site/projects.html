MAKE WITH CUKMAP

이 지도로 내 프로젝트 만들기

OT 강의실 안내, 축제 부스 지도, 시설 위치처럼 학교 공간을 다루는 프로젝트라면 지도를 새로 만들 필요가 없어요. 처음이면 30분 정도 걸려요.

  1. GitHub 가입파일을 올리고 무료로 웹페이지를 여는 곳이에요.
  2. 견본 복사견본 저장소에서 Use this template → Create a new repository
  3. content.txt 고치기제목과 장소 목록만 적어요. 예) N301 | 국어국문학과 OT | 3월 2일 10:00
  4. 페이지 열기Settings → Pages → Branch: main → Save 하면 1~2분 뒤 내 페이지가 열려요.
  5. 이름.cukmap.com 받기신청 파일 하나를 보내면 자동 검사 후 주소가 생기고, 이 목록에 올라가요.
코드는 한 줄도 쓰지 않아요. 지도 안의 「cukmap · 자료 출처」 표시만 지우지 않으면 자유롭게 써도 돼요.
