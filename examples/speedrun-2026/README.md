# 보관: 길찾기 스피드런 (2026-10 ~ 11)

cukmap이 "길 안내 지도"를 목표로 하던 시기에 만든 게임 시안이에요.
출발지와 도착지가 정해지면 지도 위를 직접 달려 도착 시간을 겨루고, 기록을 서버에 저장해 순위를 보여 줬어요.

**지금 저장소 구조에서는 그대로 동작하지 않아요.** 예전 방식(여러 패치를 덧붙여 한 파일로 굽는 구조)에 맞춰 만든 코드라서,
다시 쓰려면 지금의 `src/`·`data/` 구조에 맞게 옮겨야 해요. 지도를 활용한 프로젝트 예시로 참고용으로만 남겨 둬요.

## 파일

| 파일 | 내용 |
|---|---|
| `game.js` | 게임 화면: 출발·도착 고르기, 달리기(지상 시점), 실내 문 도착 판정, 기록 저장·순위 |
| `record-server.js` | 기록 서버(Cloudflare Pages Functions `_worker.js` 방식, D1 데이터베이스): 닉네임, 기록 검증(달리기 속도로 최소 시간 계산), 구간별 순위 |
| `build_old.py` | 예전 빌드 도구: 지도 파일에 게임을 끼워 넣던 과정 |

## 왜 멈췄나

길 안내에 필요한 정확도(출입구·계단·층 연결)를 남은 기간 안에 맞추기 어려워서,
프로젝트 방향을 "여러 사람이 함께 고쳐 나가는 지도(Make the CUKmap)"로 바꿨어요. 스피드런은 메인 목적에서 빠졌어요.
지도를 활용한 게임을 만들고 싶은 사람은 이 코드를 참고해 하위 도메인 프로젝트로 다시 만들 수 있어요.
