# cukmap 프로젝트 견본

가톨릭대학교 지도(cukmap)를 넣은 내 페이지를 **코드 없이** 만드는 견본이에요.

1. 오른쪽 위 **Use this template → Create a new repository** 로 내 저장소를 만들어요.
2. 내 저장소에서 **`content.txt` 파일만** 고쳐요. (제목, 설명, 장소 목록)
3. **Settings → Pages → Branch: main → Save** 를 누르면 1~2분 뒤 `https://내아이디.github.io/저장소이름/` 에 페이지가 열려요.
4. 원하면 `이름.cukmap.com` 주소도 받을 수 있어요.

그림과 함께 하나씩 따라 하는 설명서: https://github.com/cukmap/map/blob/main/docs/START.md

지도 안의 「cukmap · 자료 출처」 표시만 지우지 않으면 자유롭게 써도 돼요.
