# cats 서버 (/api/cats)

cats.cukmap.com(「치삼이의 츄르 대작전」 시안)이 쓰는 기록 저장소예요. 코드는 `worker/cats.js`, 표는 같은 D1(cukmap-db)에 `ct_runs`로 첫 요청 때 만들어져요.

## 규칙(값은 `worker/cats.js`의 `R`)
| 항목 | 값 |
|---|---|
| 한 판 | 3분(180초) 안에 츄르 최대한 많이. 같은 개수면 마지막 츄르를 먼저 먹은 사람이 앞 |
| 오늘의 판 | 츄르 10개. 자리는 `SPOTS`(이름 붙은 장소·건물 출입구 38곳) 중에서 한국 날짜로 정해지고 모두 같아요. 서로 30m 이상 떨어짐 |
| 먹기 | 2.6m 안으로 다가가면 |
| 랭킹 | 오늘, 사람마다 가장 좋은 판 하나(츄르 1개 이상). 학과별 합계 = 그 학과 사람들의 최고 점수 합 |
| 고스트 | 오늘 1등이 지나간 길(0.5초마다 한 점)을 다른 사람 화면에 반투명한 색 고양이로 보여 줌 |
| 부정 방지 | 길의 두 점 사이가 초속 14m보다 빠르면 거절, 먹었다는 츄르 근처를 그 시각에 지나가지 않았으면 거절, 하루 40판까지 |

## 주소
| 요청 | 하는 일 |
|---|---|
| `GET /api/cats/today` | 오늘 날짜, 규칙, 츄르 자리 10개 `{id, name, hint, x, z}` |
| `GET /api/cats/board?day=YYYY-MM-DD` | 랭킹 20등까지, 내 순위, 학과별 합계, 1등 고스트 길 |
| `POST /api/cats/run` `{day, name, dept, got:[{id,t}], path:[[x,y,z],…]}` | 한 판 올리기 → 새 랭킹 |

사람 구분은 canvas와 같아요: 브라우저가 만든 무작위 값을 `x-cats-id` 머리글로 보내고, 서버는 해시만 저장해요.
