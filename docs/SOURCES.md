# 자료 출처와 이용 조건

cukmap 지도는 아래 자료를 바탕으로 만들었다. 자료를 다시 쓸 때는 각 출처의 조건을 따른다.
자료에 문제가 있으면 GitHub 이슈로 알려 주세요. 확인 후 바로 고치거나 내립니다.

## 공개 저장소에 들어 있는 자료

| 자료 | 쓰인 곳(성심교정 폴더 기준) | 조건 |
|---|---|---|
| 국토지리정보원 2025 1:1000 수치지도 (등고선, 표고점, 건물 외곽, 옹벽) | `campus/terrain.json`, `contours.json`, `ngii-detail.json`, 건물 외곽 | 출처 표시 |
| 국토지리정보원 정사영상(국토정보플랫폼) | `images/ortho.jpg`, 지면·지붕 텍스처 | 출처 표시 |
| OpenStreetMap | 도로·보행로(`roads.json`, `network/`) | ODbL — 출처 표시, 고친 데이터도 같은 조건으로 공유. © OpenStreetMap contributors |
| 가톨릭대학교 홈페이지 입찰공고 첨부 기준 평면도(CAD) | `cad-detail.json`(주차선·옹벽·계단 등 선), 일부 건물 외곽 | 공개 게시 자료에서 위치·모양 선만 뽑아 씀(원본 파일은 넣지 않음) |
| 가톨릭대학교 공식 캠퍼스맵(평면·입체·장애인용) | 길 이름, 급경사로 위치 | 이름·위치 정보만 사용 |
| 건축물대장, 부천시 고시(층수) | `building.json`의 `ledger`, `floorSource` | 공문서의 수치만 사용 |
| 직접 만든 모델·코드 | `src/`, `details.js`, `building.json`의 `spec` | 코드 MIT(`LICENSE`) |

카카오맵 로드뷰·스카이뷰와 조원 현장 사진은 모양을 판독하는 데만 썼고, 저장소에는 넣지 않았다.

## 비공개로 보관하는 자료 (cukmap/indoor)

학교 허락을 받기 전까지 공개 저장소에 넣지 않는다. 지도 화면에서는 볼 수 있다.

| 자료 | 이유 |
|---|---|
| 입찰공고 첨부 실내 도면으로 만든 6개 동 실내 지도 | 방 단위 배치(전기실·기계실 등)까지 들어 있어 학교 확인 필요 |
| 기준 평면도 그림(도면 겹치기) | 원본 도면 그림 |
| 학교 홈페이지 사진 | 학교 저작물 |

## 라이선스

- 코드: MIT (`LICENSE`)
- 지도 데이터: 위 출처별 조건을 따른다. OpenStreetMap에서 온 길 데이터를 포함하므로 데이터 전체를 다시 배포할 때는 ODbL 조건(출처 표시, 같은 조건으로 공유)을 지킨다.
