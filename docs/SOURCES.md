# 자료 출처와 공개 여부

저장소를 공개하기 전에 모든 자료의 이용 조건을 이 표에서 확인한다. "확인 필요"가 남아 있으면 공개하지 않는다.

| 자료 | 쓰인 곳(성심교정 폴더 기준) | 공개 | 비고 |
|---|---|---|---|
| 국토지리정보원 2025 1:1000 수치지도(등고선, 표고점, 건물 외곽, 옹벽) | `campus/terrain.json`, `contours.json`, `ngii-detail.json`, 건물 외곽 | 확인 필요 | 출처 표시 조건 확인 |
| 항공사진(정사영상) | `images/ortho.jpg`, 지붕 텍스처 | 확인 필요 | 원본 제공처와 이용 조건 확인 |
| OpenStreetMap | 도로·보행로(`roads.json`, `network/`) | 공개 가능(조건부) | ODbL — 출처 표시, 같은 조건으로 공유 |
| 학교 기준 평면도(배포용 CAD) | `cad-detail.json`, `images/drawing.jpg` | 보류 | 학교 확인 전 |
| 학교 입찰공고 첨부 도면(실내 6개 동) | `buildings/*/indoor/` | 보류 | 학교에 문의 예정 |
| 학교 홈페이지 사진 | `images/evidence-0.jpg` | 보류 | 학교 저작물 |
| 건축물대장, 부천시 고시(층수) | `building.json`의 `ledger`, `floorSource` | 공개 가능 | 공문서 내용(수치)만 사용 |
| 카카오맵 로드뷰·스카이뷰 | 모양 판독에만 사용 | 이미지 공개 안 함 | 저장소에 캡처를 넣지 않는다 |
| 조원 현장 사진 | 모양 판독에만 사용 | 사진 공개 안 함 | 공개하려면 찍은 사람 동의 + 얼굴 가림 |
| 직접 만든 모델·코드 | `src/`, `details.js`, `building.json`의 `spec` | 공개 | 라이선스는 공개 전에 정함 |
