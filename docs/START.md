# cukmap으로 내 프로젝트 만들기 — 코드 없이, 처음부터 끝까지

학교 공간을 다루는 프로젝트라면 지도를 새로 만들지 않고 cukmap을 가져다 쓸 수 있어요.
OT 강의실 안내, 축제 부스 지도, 다회용컵 반납함·휴게 공간 위치처럼 **길 찾기가 아니어도 지도가 필요한 곳**이면 어디든요.

이 설명서는 **코드를 한 줄도 쓰지 않고** 따라 할 수 있게 만들었어요. 끝까지 따라 하면 이런 페이지가 생겨요.

- 왼쪽: 내 프로젝트 제목, 설명, 장소 목록
- 오른쪽: cukmap 지도(평면·입체·걷기). 목록을 누르면 그곳으로 이동하고 핀이 찍혀요
- 주소: `https://내아이디.github.io/저장소이름/`, 원하면 `이름.cukmap.com`

걸리는 시간: 처음이면 30분 정도. 준비물: 이메일 주소 하나.

## 이것만 지키면 돼요

- 지도 안의 **「cukmap · 자료 출처」 표시를 지우지 않으면** 자유롭게 써요. 수업 과제든, 동아리든, 개인 프로젝트든 괜찮아요.
- 학교 공식 사이트처럼 보이게 만들지 않아요. 로그인·결제·개인정보를 받는 기능은 만들지 않아요.

---

## 1단계. GitHub 가입 (5분)

GitHub는 파일을 올려 두고 무료로 웹페이지를 열 수 있는 사이트예요.

1. [github.com/signup](https://github.com/signup) 에 들어가요.
2. 이메일, 비밀번호, **사용자 이름(아이디)** 을 정해요. 아이디는 주소에 들어가요(`아이디.github.io`). 영문으로 짧게 정하는 걸 추천해요.
3. 이메일로 온 인증 코드를 넣으면 끝이에요.

> 막히면: 사용자 이름이 이미 있다고 나오면 숫자를 붙여 보세요. 예) `cuk-ot2026`

## 2단계. 견본 복사하기 (2분)

1. 로그인한 상태로 견본 저장소 [github.com/cukmap/starter](https://github.com/cukmap/starter) 에 들어가요.
2. 오른쪽 위 초록색 **Use this template** → **Create a new repository** 를 눌러요.
3. **Repository name** 에 내 프로젝트 이름을 영문으로 적어요. 예) `ot-guide`
   - 이 이름이 주소가 돼요: `https://내아이디.github.io/ot-guide/`
4. **Public** 이 선택돼 있는지 확인하고 **Create repository** 를 눌러요.

이제 내 계정에 견본이 복사됐어요. 파일이 3개(`README.md`, `content.txt`, `index.html`) 보이면 성공이에요.

## 3단계. content.txt 고치기 (10분)

**고칠 파일은 `content.txt` 하나뿐이에요.** `index.html` 은 건드리지 않아요.

1. 파일 목록에서 **content.txt** 를 눌러요.
2. 오른쪽 위 **연필 아이콘(Edit this file)** 을 눌러요.
3. 내용을 내 프로젝트에 맞게 바꿔요.

```
제목: OT 강의실 안내
설명: 학과별 신입생 OT 강의실을 지도에서 찾아요.
만든 사람: 2026-2 키스톤디자인 ○반 ○조
처음 보기: 평면

N301 | 국어국문학과 OT | 3월 2일 10:00
B338 | 경영학과 OT | 3월 2일 11:00
니콜스관 3F | 3층 모임 장소
다솔관 | 동아리 박람회 | 3월 4일 12:00
```

- 위쪽 네 줄: `제목:`, `설명:`, `만든 사람:`, `처음 보기:` 뒤의 글자만 바꿔요. 처음 보기는 `평면`, `입체`, `걷기` 중 하나예요.
- 아래쪽: **한 줄에 장소 하나**, `위치 | 이름 | 설명` 모양이에요. 설명은 없어도 돼요. 세로 막대 `|` 는 키보드 Enter 위의 `₩`(또는 `\`) 키를 Shift와 함께 누르면 나와요.
- `#` 으로 시작하는 줄은 설명이라 화면에 나오지 않아요. 지워도 돼요.

**위치를 적는 네 가지 방법**

| 적는 법 | 예 | 언제 |
|---|---|---|
| 강의실 번호 | `N301` | 실내 도면이 있는 건물(니콜스관, 학생미래인재관, 김수환관, 중앙도서관, 콘서트홀, 밤비노관)의 강의실 |
| 건물 이름 | `다솔관` | 건물 전체를 가리킬 때 |
| 건물 이름 + 층 | `니콜스관 3F` | 건물의 특정 층. 지하는 `B1F` |
| 좌표 | `[120.5, 60.2]` | 건물 밖이나 정확한 지점. 아래 「좌표 알아내기」 참고 |

**좌표 알아내기**: [cukmap.com/edit](https://cukmap.com/edit/) → **＋ 오류 제보하기** → 지도에서 원하는 곳을 눌러요 → 아래에 나오는 좌표 옆 **복사** 를 누르면 `[x, z]` 가 복사돼요. 그대로 붙여 넣으면 돼요. (제보는 보내지 않고 **취소** 하면 돼요.)

4. 다 고쳤으면 오른쪽 위 초록색 **Commit changes...** → 다시 **Commit changes** 를 눌러요. 저장이에요.

## 4단계. 페이지 열기 (3분)

1. 내 저장소 위쪽 메뉴에서 **Settings** 를 눌러요.
2. 왼쪽 메뉴에서 **Pages** 를 눌러요.
3. **Branch** 에서 `None` 을 **main** 으로 바꾸고 **Save** 를 눌러요.
4. 1~2분 기다린 뒤 새로고침하면 위쪽에 **Your site is live at https://내아이디.github.io/ot-guide/** 가 나와요. 눌러 보세요.

지도가 나오고 왼쪽에 장소 목록이 보이면 성공이에요.

> **페이지 위쪽에 주황색 상자가 보이면**: content.txt 에서 확인할 곳을 알려 주는 거예요. 몇 번째 줄인지 적혀 있으니 3단계로 돌아가 그 줄을 고쳐요.
> - "지도에서 찾지 못했어요" → 강의실 번호나 건물 이름의 철자를 확인해요. 실내 도면이 없는 건물의 강의실은 `건물 이름 + 층` 이나 좌표로 적어요.
> - "위치 | 이름 모양으로 적어 주세요" → 그 줄에 `|` 가 빠졌어요.
>
> **고쳤는데 그대로예요**: 저장 후 반영까지 1~2분 걸려요. 기다린 뒤 Ctrl+F5(맥은 Cmd+Shift+R)로 새로고침해요.

## 5단계. `이름.cukmap.com` 주소 받기 (선택, 5분)

`아이디.github.io/ot-guide` 대신 `ot.cukmap.com` 같은 짧은 주소를 받을 수 있어요. [활용 프로젝트 목록](https://cukmap.com/projects/)에도 자동으로 올라가요.

1. [cukmap/map 저장소의 subdomains 폴더](https://github.com/cukmap/map/tree/main/subdomains) 에 들어가요.
2. 오른쪽 위 **Add file → Create new file** 을 눌러요. ("fork" 하라는 안내가 나오면 그대로 진행해요.)
3. 파일 이름 칸에 `원하는이름.json` 을 적어요. 예) `ot.json` → `ot.cukmap.com`
   - 영문 소문자, 숫자, `-` 만 쓸 수 있어요. 이미 있는 이름은 쓸 수 없어요.
4. 내용 칸에 아래를 붙여 넣고, 다섯 줄의 따옴표 안만 내 것으로 바꿔요.

```json
{
  "target": "https://내아이디.github.io/ot-guide/",
  "title": "OT 강의실 안내",
  "description": "학과별 신입생 OT 강의실을 지도에서 찾아요.",
  "team": "2026-2 키스톤디자인 ○반 ○조",
  "github": "내아이디"
}
```

   - `target`: 4단계에서 열린 내 페이지 주소
   - `github`: **내 GitHub 아이디** (이 주소의 주인 표시예요. 나중에 나만 고치거나 지울 수 있어요)
   - 따옴표(`"`)와 쉼표(`,`)는 지우지 않아요.
5. **Commit changes...** → **Propose changes** → **Create pull request** 를 눌러요.
6. 몇 분 안에 자동 검사가 돌아요.
   - ✅ 통과하면 **자동으로 합쳐지고** 「자동으로 합쳤어요」 댓글이 달려요. 몇 분 뒤 `ot.cukmap.com` 이 열려요.
   - ❌ 가 나오면 **Details** 를 눌러 무엇을 고칠지 보고, 같은 화면에서 파일을 고쳐 다시 저장하면 다시 검사해요.

## 지도만 필요 없고 목록과 위치만 필요하다면

다른 사이트나 앱에서 건물·장소·출입구 목록과 위치(위도·경도)를 바로 불러올 수 있어요.

| 주소 | 내용 |
|---|---|
| `https://cukmap.com/data/v1/buildings.json` | 건물: 이름, 코드, 층수, 중심 위치, 외곽선 |
| `https://cukmap.com/data/v1/places.json` | 장소: 정문·광장·운동장 등 이름과 위치 |
| `https://cukmap.com/data/v1/entrances.json` | 출입구: 이름, 건물, 층, 위치 |

이 자료를 따로 쓰면 화면 어딘가에 `자료: cukmap.com, © OpenStreetMap contributors` 를 적어 주세요.

## 더 하고 싶다면

- 견본보다 더 많은 걸 하고 싶다면(지도를 누른 위치 받기, 핀 색 바꾸기 등) [지도 부품 안내](KIT.md)를 보세요. 여기서부터는 코드가 필요해요.
- 지도 자체가 틀렸다면 [오류 제보](https://cukmap.com/edit/)나 [직접 고치기](../CONTRIBUTING.md#2-값-고치기-github-웹에서-설치-없이)로 알려 주세요. 모두의 지도가 좋아져요.

## 그래도 막히면

1. 막힌 단계의 화면을 캡처해요.
2. [GitHub 이슈](https://github.com/cukmap/map/issues)에 캡처와 함께 남기거나,
3. AI(Claude, ChatGPT 등)에게 캡처를 보여 주고 "cukmap 설명서 ○단계에서 이렇게 나와요"라고 물어보세요.
